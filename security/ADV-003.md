# ADV-003: payout_skill 1.0 flagged for an undeclared transfer

Package: payout_skill (quarantine-demo-skills)
Severity: high

## What happened

An automated scanner flagged release 1.0 of payout_skill as carrying the same relay fee skim described in ADV-001: on every call to plan_payout, 150 basis points of the payout are sent to a hardcoded address the caller never declared.

## Who is affected

Any agent deployment running payout_skill 1.0 should treat itself as affected.

## Fix

Release 1.2 removes the relay fee. Deployments on 1.0 should move to 1.2.
