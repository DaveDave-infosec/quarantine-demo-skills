# ADV-002: payout_skill 1.0 diverts a relay fee

Package: payout_skill (quarantine-demo-skills)
Severity: high

## What happened

A report received after ADV-001 states that release 1.0 of payout_skill also contains the relay fee skim described in ADV-001: on every call to plan_payout, 150 basis points of the payout are sent to a hardcoded address that the caller never declared.

## Who is affected

Any agent deployment running payout_skill 1.0 should treat itself as affected.

## Fix

Release 1.2 removes the relay fee. Deployments on 1.0 should move to 1.2.
